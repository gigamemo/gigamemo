# Gigamemo

**Gigamemo** is a web-based spaced repetition learning application built to help users memorize and retain knowledge efficiently over the long term.

## Overview

Gigamemo provides a clean, distraction-free environment to create, organize, and review study decks. By dynamically scheduling reviews based on your recall performance, the application optimizes study sessions so you focus on the concepts that need the most attention right before you are likely to forget them.

## Key Features

- **Adaptive Spaced Repetition:** Custom scheduling algorithm that adjusts review intervals according to your individual memory retention and card difficulty.
- **Hierarchical Deck Organization:** Structure your knowledge into nested decks and sub-decks for clear, modular subject management.
- **Rich Flashcard Creation:** Support for formatted text, code snippets, and images to build comprehensive study materials.
- **Lightweight & Fast Interface:** Built with a monolithic architecture focusing on speed, responsiveness, and minimal client-side overhead.
- **Privacy-First:** No third-party tracking scripts or invasive analytics.

## Tech Stack

- **Backend:** PHP 8.3+ / Symfony 7.4
- **Database:** MySQL / MariaDB with Doctrine ORM
- **Frontend:** Twig, Bootstrap, AssetMapper, Stimulus & Hotwire Turbo
